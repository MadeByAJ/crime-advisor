A Crime Advisor button sits in the bottom-left corner of the Crimes pages. It opens a panel with your API key, how far the log download has got, and a table of your $/nerve per crime, all time and for the last 30 days.

The numbers are net. Materials you used (fuels, candles, email lists) are subtracted and item rewards are counted, both at today's market price. Scamming includes the nerve spent farming emails and sending spam waves.

Install

  1. Get Tampermonkey

    Install the Tampermonkey extension for Chrome, Edge or Firefox from tampermonkey.net. In Chrome and Edge, also turn on Allow user scripts (or Developer mode) for the extension when it asks.

  2. Add the script

    Install Crime Advisor

    Tampermonkey opens its install page: press Install. Installed this way it keeps itself up to date.

    If the button only shows the code, copy it from the box below instead: in Tampermonkey choose Create a new script, select everything in the editor, paste over it, and save with Ctrl+S.

    crime-advisor.user.js · 852 lines

  3. Make a Custom API key with only "log"

    Torn's key form has no Custom option of its own, so use this link. It opens the form pre-filled with a key named "Crime Advisor" that can only read logs: make a log-only key. Check it lists only log, create it, and copy the key. The same link is in the script's panel.

    Torn only shows crime logs to keys with log access. A Limited key won't work. A Full key works but gives the script more than it needs, so use the log-only one.

  4. Paste the key into the panel

    Go to any Crimes page, click Crime Advisor in the bottom-left, paste the key and press Save key. It checks the key straight away and tells you if Torn refuses it.

  5. Let it read your history

    Your newest logs load first, so buttons appear within a few seconds. Older logs then load in the background at 100 logs every 3 seconds: about 5 minutes per 10,000 crime logs. That's roughly 20 of Torn's 100 calls a minute, so your other tools keep working. The numbers update every 2,000 logs as it goes. It carries on from where it stopped next time you open Torn, and only one tab downloads at a time (the others say so).

Without a key

Arson still works with no key at all. Each job gets a button with the community's payout range and recipe (what to place, what to ignite with, when to stoke), the job's requirements, and a red warning on a job that needs 100% and topped out short of it.

Your key and your data

Data storageOnly in your browser. Your crime logs go into the browser's own storage (IndexedDB) so they aren't downloaded twice. Settings and your key are kept by Tampermonkey.
Data sharingNone. Nothing about you leaves your browser.
Purpose of usePersonal: your own $/nerve per crime.
Key storage & sharingStored in Tampermonkey on this browser. Sent only to api.torn.com.
Key access levelCustom, with log only.
Other downloadsPublic arson recipes from balaclava.app (the Arsonist's Ledger) and item prices from Torn, each refreshed once a day. No key is sent with the recipe download.

It's read-only. It never clicks, commits a crime or does anything in Torn for you. Each browser keeps its own copy, so a second computer downloads your history again.

What's new in 1.2.0

  • Disposal works for every job. Only Broken Appliance and Firearm got a button before: the logs say "abandoning some general waste", which didn't match the page's General Waste.
  • Which disposal method to use. Each job's button names the method with the best expected $/nerve ($19k/nerve · abandon), and its card rates every method: reliability (the chart's colours), nerve, expected $/nerve and your critical fails. Reliability starts from the community's disposal chart (Feb 2024, 35,517 disposals) and follows your own results. Cheap and shaky can beat sure and dear: abandoning a dead body (6 nerve, ~80%) usually beats burning it (10 nerve, ~90%), which is why veterans leave them.
  • Newer forgery projects are counted. Holographing a Travel Visa, programming or chipping an ID Badge, casting or polishing a Skeleton Key, framing, branding and gluing weren't recognised: their nerve was left out, so Forgery read higher than it should.
  • Bootlegging's online store is counted. Setting it up and collecting its funds were left out, so Bootlegging read lower than it should.
  • Arson: no Flamethrower on accidental jobs (1.2.1). When a job's requirements call for an accidental cause or insurance and the community recipe lights or stokes with the Flamethrower, its button shows a warning and the card swaps in a Lighter: the Flamethrower isn't accidental, so it fails the job.
  • Graffiti by district. Each district on the Graffiti page gets its own button.

Your stored logs are re-read with the new rules: nothing needs downloading again.

Updating

It updates itself: Tampermonkey checks this site for a new version about once a day (or straight away with Check for userscript updates in its menu). Your key and the logs you've already downloaded are kept.

Pasted it in by hand before this page existed? Press Install Crime Advisor above once: Tampermonkey offers it as an update to your existing copy, keeping your key and logs, and it updates itself from then on.

If something's off

"the key can't read logs"
The key has no log access. Use Make a log-only key in the panel and paste the new key with Replace key.
"the API key isn't right"
The key was mistyped or deleted on Torn. Copy it again from Settings › API Keys; it's 16 letters and numbers.
"too many requests: waiting"
Other tools used up Torn's 100 calls a minute. The script waits a minute and carries on by itself.
No buttons on a crime page
Buttons only appear for things you've done before (or community arson jobs). Check the panel: if the log count is still climbing, give it a few minutes. Also check Tampermonkey shows the script as enabled on torn.com.
"your logs are re-read each visit"
The browser is blocking storage, usually a private window. It still works, but only on your most recent ~2,000 logs. Use a normal window to keep the full history.
A number looks wrong
Prices are today's market values, so old materials and rewards are re-priced. Crimes where the money lands on a later step than the nerve (card skimming, for one) are valued as a whole crime rather than per target.
Start over
Panel › Remove key and data clears your key and every stored log from this browser. Deleting the key on Torn stops it working everywhere.
